# CHECKPOINT-27 — cold-reader reproduction contract

**Mission.** Prove a cold reader can reproduce headline results without
undocumented knowledge.

**Required evidence.** Root `REPRODUCE.md`, friction log, cold-start transcript,
peer attempt, and executable Checkpoint 27.

**Fail condition.** Any undocumented command, choice, version, path, credential,
edit, or interpretation is required to reach the numbers.

The machine gate requires:

1. one parseable clone-to-number block;
2. exact public URL, revision, directory, prerequisites, and expected values;
3. execution of that block verbatim in a fresh clone;
4. all six headline strings in the transcript;
5. zero reader questions and zero operator improvisations;
6. every friction item resolved and verified;
7. one independent no-context peer attempt using only the document.

The generated outcome is `evidence/CHECKPOINT-27.md`; full audit details are in
`evidence/reproduction_audit.json`.
