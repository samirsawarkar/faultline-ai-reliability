# First 72 hours after launch

## T+0–24 · prove the public path

Owner: repository owner.

- Re-run the clone-to-number path from a clean public checkout.
- Watch CI and reproduction failures.
- Record comprehension questions without debating them.

Gate: one independent reader reaches the headline number with zero undocumented
improvisations.

Rollback: withdraw the launch link and repair the first undocumented assumption
before more outreach.

## T+24–48 · selective expert exposure

Owner: repository owner.

- Send only the two highest-fit reviewed messages.
- Answer with result links and limitations.
- Open the approved documentation contribution.

Gate: two durable expert-message receipts and one OSS contribution URL exist.

Rollback: stop outreach if a target calls the message off-topic or a linked
claim fails its audit.

## T+48–72 · convert objections into work

Owner: repository owner.

- Cluster objections by evidence, scope, and usability.
- Re-run the affected checkpoint before changing a claim.
- Publish a 72-hour keep/change/stop note.

Gate: every substantive objection has an owner, evidence link, and disposition.

Rollback: retract or narrow any claim no longer supported by its committed
result.

Across all windows, keep correct-service success, mean cost, and p95 latency
separate. Never treat engagement as reliability evidence.
